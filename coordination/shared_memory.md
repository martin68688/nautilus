## Project Goal

- Build a **procedural Skill Graph memory** on top of the mlevolve solver; target NeurIPS/ICML/ICLR 2026.
- Data flow: `mlevolve trace → improved Trace2Skill distillation → Skill Graph (NetworkX) → agent multi-hop retrieval → conflict-aware decisions`.
- Novelty: (1) nodes are *procedural skills/SOPs* (other graph-memory systems store facts/events/entities/cases — procedural graphs are open ground); (2) methodology relation edges (applies_when / prevents / refines / conflicts_with) surface links that vector retrieval misses.
- v3 three phases: **P1** distillation (structured patch, recall gate ≥10/15 vs hand-written ground truth) → **P2** graph build (6 node types, 7 edge types) → **P3** agent multi-hop (3 tools; only modify `improve_agent.py` + `agent_search.py`; `debug_agent.py` frozen as control).
- Two memory layers must NOT merge: Layer A = per-branch trace memory (force-injected, read-only in run); Layer B = Skill Graph (on-demand tool query).
- Scope: latest review (2026-06-30) narrowed the paper to **single task** (spooky-author-identification); full MLE-bench deferred to future work.

## SkillGraph Competitor & Static Baseline (synced 2026-07-02)

- **SkillGraph = arXiv:2605.12039** ("Skill-Augmented RL via Evolving Skill Graphs", USTC/Alibaba/NUS, 2026-05, Under Review). **No public code → hand-roll.** It is the COMPETITOR our own method positions against: SkillGraph has only general/task nodes + 3 positive edges (prereq/enhance/co_occur) + level, and **no conflict handling** (our novelty = `prevents`/`conflicts_with` + multi-hop). Paper has no published distillation prompt (only paraphrased in Appendix E).
- **Paper mechanics**: node = compact 4-field card {title, principle, condition, category=general|task_type} + framework {level, n_use, n_succ, p_hat}; **no references/embeddings**. 3 stages: (1) construction — teacher `M(T+,T-)` distills; InitGraph (A.2): co_occur within task-type w=0.3, enhance all general→task-specific w=0.2, **zero prereq at init**; levels over {prereq,enhance}. (2) retrieval §3.2 — seed=general∪task-matched → backward-BFS depth D=2 over incoming prereq → forward-beam width B=3 (σ=max_parents σ·w) → topo-sort → cap K_max=8; **multi-task by design**. (3) evolution — Insert/Merge(neighbor-Jaccard≥0.85)/Split/Deprecate + path-reinforce/decay/prune + progressive-unlock + GRPO co-evolution.
- **Our static baseline = the paper's "w/o Graph Evolution" ablation** (build init graph only, NO online evolution). Pipeline in `paper-skills/distillation/` (**4 untracked graph builders** — fresh-clone footgun, Codex-flagged): `distill_skillgraph_nodes` (batch-pool of branches, DeepSeek v4-flash = paper's o3 substituted, category folded, emits evidence_turns), `build_references` (references/*.md are OUR extension — paper nodes have none), `build_edges_levels` (InitGraph + levels + stats-proxy), `merge_nodes` (build-time text-similarity + teacher-merge dedup).
- **Full-93 run done**: 177→162 merged nodes; `graph_build/graph.json` = 162 nodes, 5807 edges (enhance 5472 + co_occur 335, prereq 0), levels {0:48, 1:114}; 162 references, all evidence-grounded. Source = the 17 clean runs (incl. A100 `elite-peach-mayfly` best 0.1007).
- **Documented faithfulness deviations**: teacher o3→DeepSeek; no RL rollout → stats are trace-evidence proxy (n_use=branch-count, noisy); no evolution → no Merge/deep-levels/progressive-unlock; references are our addition (paper nodes are compact cards).
