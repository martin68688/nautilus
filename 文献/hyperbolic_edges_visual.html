🔗 双曲图里，"边"是怎么表达的？

核心：边不是额外存的东西，是 A、B 两个节点几何位置关系的自动结果。

先记住：两个量决定一切

每个节点在双曲空间有两个坐标。任意两个节点 A、B 的关系，只看这两个量的对比：

① 半径差 Δr = r_B − r_A

半径差告诉你：层级关系

② 角度差 Δθ = θ_B − θ_A

角度差告诉你：语义关系

所以"边"= (Δr, Δθ) 这对数值的组合。不同组合 → 不同类型的边。下面逐个看。

你的 7 类边 → 7 种 (Δr, Δθ) 组合

① refines（细化）
Δr > 0, Δθ ≈ 0
A 是通用方法，B 是它的细化版。
例：A="梯度下降" → B="带动量的Adam"
② prerequisite（前置）
Δr > 0, Δθ ≈ 0（强序）
A 是 B 的前置条件。
例：A="数据清洗" → B="特征工程"
③ alternative（替代）
Δr ≈ 0, Δθ 小
A、B 同层级同类，可互换。
例：A="XGBoost" ↔ B="LightGBM"
④ co_occurs（共现）
Δr ≈ 0, Δθ 小
A、B 在成功 trace 里常一起用。
例：标准化 + 正则化
⑤ applies_when（适用条件）
Δr < 0（跨层）, Δθ 中
条件节点 C 指向适用它的 skill A。
例：C="小数据集" → A="用交叉验证"
⑥ supported_by（证据支撑）
Δr < 0（包含）, Δθ ≈ 0
skill A 由证据 E 支撑（A 包含 E）。
例：A="dropout有效" ← E="实验日志"
⭐ prevents（冲突）
Δr ≈ 0, Δθ ≈ π（180°对跖）
你的王牌：两个都 metric-真但互斥。
例：A="增大数据" vs B="精简数据"
💡 关键领悟：你不需要像普通图那样存 (A, prevents, B) 这条记录。 只要 A 和 B 在双曲空间被放在了对跖位置（角度差≈180°），它们的几何关系自动就是 prevents。 检索时算一下角度差，就知道这俩是冲突的。

速查表：(Δr, Δθ) → 边类型

半径差 Δr角度差 Δθ边类型含义
大（B 更具体）≈0（同方向）refines / prerequisiteB 是 A 的细化或前置
≈0（同层）小（方向近）alternative / co_occurs同层同类，可互换或共现
负（跨层）中applies_when外层条件指向内层 skill
负（包含）≈0（同方向）supported_byA 包含证据 E
≈0（同层）≈π（对跖）prevents ⭐同层但对立冲突

检索时：边不是"走"的，是"算"的

普通图检索 = 遍历边列表（从 A 出发，找所有 prerequisite 边连到的节点）。 双曲检索 = 算几何（从 query 点出发，算哪些点满足某类边的几何条件）。

普通图遍历

找 edges.filter(type=='prerequisite')
→ 遍历每个候选
→ 受限于显式存储的边

双曲几何检索

query q 的位置已知
→ 找所有满足 Δr>0 且 Δθ≈0 的点
→ 这就是"q 的所有 prerequisite"
→ 不受显式边限制，全空间都能算

为什么这是混合检索：因为"算几何"时，你可以同时加多个条件—— "找 Δθ≈0（语义近）且 Δr 合理（层级合适）的点"。 语义和层级在一个公式里同时满足，这就是平面系统做不到的"统一"。

一句话总结

普通图的边 = 你存的一条记录；双曲图的边 = 两点位置关系的几何结果。
你用 (半径差 Δr, 角度差 Δθ) 这对数，就能自动判断任意两个节点是什么关系—— 细化、前置、替代、共现、条件、支撑、冲突。 其中"冲突=对跖"是任何平面图都表达不了的，是双曲给你的独有能力。
