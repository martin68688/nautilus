🌳 演化深度半径 · 可视化

看懂"新旧 / 有效 / 无效"的 skill 在 Poincaré 球里分别落在哪，以及为什么 r 能统一表达层级与时序。

① 起点：生物学系统发生树（直觉来源）

演化深度半径的直觉来自生物系统发生树——一棵树的"距根距离"天然同时编码两件事：

① 演化时间（新旧）

离根越远 = 分化越晚 = 越新

② 特化程度（层级）

离根越远 = 越特化 = 越具体

关键：在这棵树里，"新"和"特化"是耦合的——Transformer 既比线性模型新、也比它特化。这就是 r 能统一表达两者的前提。

② 映射：演化树怎么"卷"进 Poincaré 球

系统发生树是"线性展开"的，双曲空间是"圆形"的。映射的关键：把树根钉在球心，让分支沿不同方向（角度 θ）向外生长。

映射规则：树根钉在球心（r=0）；每个分支选一个角度方向 θ（不同领域不同方向）；沿该方向向外生长时 r 递增。越靠边缘 = 越新、越特化、r 越大。

③ 核心图：四类 skill 在球里落在哪

按 metric_delta（有效性）× recency（新旧）的组合，skill 分四类。看它们在 Poincaré 球里各自的位置：

① 核心·基石（旧+有效）

r 最小，靠球心。例：原生 AutoModel 微调（log loss 低）。多次实验都证明有效（log loss 低），是演化谱系的根基。检索权重最高。

② 核心前沿（新+有效）

r 小偏外，核心区边缘。例：新蒸馏出的高效 trick。既有效又新，是演化的当前前沿。靠 refines 边连回 S1。

③ 边缘·试探（新+无效）

r 中大，靠边缘。例：刚试的新方法没 work。新但无效，推到边缘。但双曲边缘有指数体积，它不被丢弃，保持可达（等你找到适用条件）。

④ 边缘·淘汰（旧+无效）

r 最大，最边缘。例：古老的失败方法。既旧又无效，但几何保护下仍可被追溯（避免重蹈覆辙）。

关键看图里 S1→S2 的 refines 边：从核心基石"长"向核心前沿，方向向外（r 递增）。这就是 r 同时表达"演化时间"和"特化层级"的几何证据——S2 比 S1 既新、又更特化，所以 r 更大。

④ 半径怎么算：metric + recency 融合

r 不是单一信号，是有效性 + 时序两个信号的融合（因为两者在演化里耦合）：

r = sigmoid( α · norm(effectiveness) + β · norm(recency) ) 推荐 α = 0.9（有效性为主）, β = 0.1（时序为辅）

注意 metric 方向：spooky 是 log loss 任务（maximize=False），越低越好。effectiveness = norm(1/metric) 或 norm(−metric)，使"有效"映射为大值。recency 归一化到 [0,1]（最新=1）。sigmoid 保证 r 落在 (0,1) 的 Poincaré 球内。

权重依据：真实数据验证（124 个无泄露节点）显示 step-metric 相关仅 −0.008（几乎无关），故 recency 权重压到 0.1，metric 主导。

四类 skill 的 r 计算（示例）

skilleffectivenessrecencyr = σ(0.9·eff + 0.1·rec)落点
S1 原生AutoModel0.9（log loss低，有效）0.1（很旧）σ(0.82) → 映射后小核心
S2 DeBERTa微调0.8（有效）0.9（很新）σ(0.81) → 映射后小偏外核心前沿
S3 attention pool0.2（log loss高，无效）0.8（新）σ(0.26) → 映射后大边缘·试探

注意 r 经 sigmoid 后单调映射到球的半径——S1/S2 最靠核心（effectiveness 高），S3/S4 靠边缘。新旧与有效性通过加权和统一到一个标量，但 effectiveness 权重压倒性主导。

⑤ 时序边怎么从 r 几何派生

有了演化深度半径，时序关系不用额外存，从 r 自动派生：

几何条件（从 r 派生）时序含义边类型
r_B > r_A 且 Δθ≈0B 比 A 新且更特化refines
r_B > r_A 且 Δθ≈0 且 B 有效B 是 A 的更好更新版superseded_by
r_B > r_A（纯时序）B 严格晚于 Asuccessor_of
结论：时序边是 r 的免费副产品。你不需要像 Zep 那样额外存 valid_at 时间戳——只要 r 编码了演化深度，"谁更新"就能从 r 的大小关系自动读出。

⑥ 什么时候这个方案会失效（必须诚实写进 Limitations）

⚠️ 三种"耦合失效"情况——此时新旧与特化解耦，r 算不准

a. 范式革命

例：SGD → Transformer。新方法反而更通用（r 该小），但时序新（r 该大）。冲突。

对策：r 服从 metric（Transformer 有效则 r 小）；时序用时间戳元数据。

b. 回滚

例：新方法不如旧的，回退。新 skill 的 r 应该小于旧 skill。违背"新=外"假设。

对策：r 服从 metric_delta（旧更有效则 r 更小）。

c. 并行演化

例：两个 skill 同时代，r 相同。无法从 r 判时序先后。

对策：靠角度 θ 区分方向，r 不背时序；精确先后用时间戳。

统一兜底原则：当"新旧"与"层级"耦合失效时，r 始终服从 metric_delta（有效性优先），时序的精确先后用节点的时间戳元数据补充。论文里把这个分层设计讲清楚（r 主载有效性、时序是耦合时的副产品、失效时退回元数据），反而显得严谨。

⑦ 一页纸总结

🌳 演化深度半径 = 一个 r 同时承载"有效性层级"和"演化时序"

为什么成立：在 MLE skill 演化里，新 skill 通常是从旧 skill 细化来的——"新"和"特化"天然耦合（与生物系统发生树同构）。

公式：r = sigmoid(0.9·effectiveness + 0.1·recency)（effectiveness = norm(1/metric)，因 log loss 越低越好）。四类 skill 落点：核心基石(旧+有效)→核心前沿(新+有效)→边缘试探(新+无效)→边缘淘汰(旧+无效)。

时序边免费派生：refines/superseded_by/successor_of 都从 r 大小关系自动读出，无需额外存时间戳。

失效兜底：范式革命/回滚/并行演化时，r 服从 metric_delta，精确时序退回时间戳元数据。
