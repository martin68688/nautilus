## 🏆 Run 4 详细分析（最佳性能 - 0.2013）

### 运行信息
- **运行时间：** 2026-05-09 20:40
- **最佳Log Loss：** 0.2013
- **方法：** DeBERTa-v3-large + XGBoost + Logistic Regression 三模型集成
- **特点：** 详细特征工程 + 渐进式解冻 + 加权集成

### 整体架构：三模型集成

Run 4采用了**三个独立模型的加权集成**策略：

```
模型1: DeBERTa-v3-large微调
模型2: XGBoost (DeBERTa嵌入 + 手工特征)
模型3: Logistic Regression (TF-IDF n-grams)
         ↓
    加权集成 (网格搜索最优权重)
         ↓
    最终预测
```

**最优集成权重：**
- DeBERTa-v3-large: ~0.65
- XGBoost: ~0.25
- Logistic Regression: ~0.10

### 模型1：DeBERTa-v3-large 微调

#### 模型配置

| 参数 | 值 | 说明 |
|------|-----|------|
| **模型** | microsoft/deberta-v3-large | 435M参数 |
| **架构** | 24层Transformer | 解耦注意力机制 |

#### 分类头设计

```python
DeBERTa-v3-large Transformer
         ↓
    [CLS] token (1024维)
         ↓
    Dropout (0.2)
         ↓
    Linear (1024 → 3)
         ↓
    Logits → Softmax
```

**关键点：**
- 使用 `AutoModelForSequenceClassification`
- HuggingFace自动添加分类头
- 输出logits，手动应用softmax

#### 训练策略：渐进式解冻

**阶段1：冻结训练（前5个epoch）**
- 冻结所有Transformer层
- 只训练分类头
- 学习率：标准

**阶段2：渐进式解冻（之后）**
- 每个epoch解冻一层
- Layer-wise学习率衰减：0.95
- 从顶层向底层逐步解冻

**优势：**
- 避免灾难性遗忘
- 保留预训练知识
- 逐步适应任务

## 🔄 Run 5 详细分析（0.3368）

### 运行信息
- **运行时间：** 2026-05-10 凌晨
- **最佳Log Loss：** 0.3368
- **方法：** ModernBERT-large + TF-IDF特征融合
- **特点：** Layer-wise学习率 + 梯度中心化 + 特征层融合

### 整体架构：单模型特征融合

Run 5采用了**单一模型的特征层融合**策略：

```
输入文本
    ↓
[ModernBERT分支]     [TF-IDF分支]
    ↓                    ↓
[CLS]嵌入(768)      Stylometric Encoder(16)
    ↓                    ↓
    ←─── 拼接 (784维) ───→
              ↓
        MLP分类器
              ↓
      Logits → Softmax
```

### ModernBERT配置

| 参数 | 值 | 说明 |
|------|-----|------|
| **模型** | answerdotai/ModernBERT-large | ~330M参数 |
| **上下文长度** | 8k tokens | BERT的16倍 |
| **隐藏维度** | 768 | - |
| **最大输入长度** | 512 tokens | 实际使用 |
| **Dropout** | 0.3 (hidden), 0.2 (attention) | 高dropout防过拟合 |

**ModernBERT特点：**
- ✅ 现代化架构，训练效率高
- ✅ 8k上下文长度（虽然只用了512）
- ✅ 不使用token_type_ids
- ✅ 2T tokens预训练数据

### 自定义分类头

```python
# Stylometric MLP encoder (TF-IDF → 16维)
stylometric_encoder = nn.Sequential(
    nn.Linear(256, 64), LayerNorm, ReLU,
    nn.Linear(64, 32), LayerNorm, ReLU,
    nn.Linear(32, 16), LayerNorm, ReLU,
)

# MLP分类器 (768+16 → 3)
classifier = nn.Sequential(
    nn.Linear(784, 512),
    nn.ReLU(),
    nn.Dropout(0.3),
    nn.Linear(512, 3),  # 输出logits
)
```

## 💡 关键发现

### 1. 集成的威力 ⭐⭐⭐

**Run 4的成功证明：**
- 多模型集成 > 单一大模型
- 模型互补性很重要
- DeBERTa (0.65) + XGBoost (0.25) + LogReg (0.10)

**启示：**
即使单个模型不是最优，通过集成也能获得显著提升。

### 2. 特征工程的重要性 ⭐⭐⭐

**Run 4 vs Run 5：**
- 39维详细特征 vs 仅TF-IDF
- 风格统计特征对作者识别至关重要
- 预训练模型无法完全替代手工特征

**启示：**
对于作者识别任务，风格特征是核心竞争力。

### 3. 融合层次的影响 ⭐⭐

**概率层集成 vs 特征层融合：**
- Run 4: 每个模型独立训练，概率层融合
- Run 5: 特征层拼接，联合训练

**结果：**
概率层集成表现更好，可能因为：
- 模型独立性更强
- 避免了联合训练的复杂性
- 更容易调优

### 4. 预训练模型的选择 ⭐⭐

**DeBERTa-v3-large vs ModernBERT-large：**
- DeBERTa: 435M参数，解耦注意力
- ModernBERT: 330M参数，8k上下文

**结果：**
DeBERTa在作者识别任务上表现更好，可能因为：
- 更大的模型容量
- 解耦注意力更适合捕捉风格
- 虽然ModernBERT有8k上下文，但任务只需512

### 5. 训练稳定性 ⭐

**Run 5的NaN问题：**
- Epoch 2-5出现validation log loss NaN
- 可能原因：学习率过大、label smoothing不足
- 影响最终性能

**启示：**
训练稳定性对最终性能有重要影响。

## 📈 最佳实践总结

基于Run 4和Run 5的经验，以下是作者识别任务的最佳实践：

### 1. 模型选择

**推荐：** DeBERTa-v3-large
- 解耦注意力机制
- 适合风格识别
- 435M参数，容量充足

**备选：** ModernBERT-large
- 训练效率高
- 8k上下文（如果需要）
- 330M参数，较轻量

### 2. 特征工程

**必须包含：**
- ✅ 风格统计特征（标点、大小写、词长等）
- ✅ 可读性特征
- ✅ 字符级特征（CharCNN或n-gram）
- ✅ 词汇特征（功能词、情感词、古体词）

**可选：**
- TF-IDF n-gram
- POS特征
- 句法特征

### 3. 训练策略

**推荐：**
- ✅ 渐进式解冻（避免灾难性遗忘）
- ✅ Layer-wise学习率（backbone小，新层大）
- ✅ Label smoothing (0.1)
