### 模型架构：MultiInputClassifier

这是一个**高度定制的深度神经网络**，采用三路并行特征提取 + 交叉注意力融合的架构。

#### 1. 三路特征提取分支

**分支A：TF-IDF 文本特征分支**
```
输入：TF-IDF向量（词频-逆文档频率）
网络结构：
  TF-IDF → Linear(384) → LayerNorm → GELU → Dropout(0.6) 
         → StochasticDepth(0.9) → Linear(192) → LayerNorm 
         → GELU → Dropout(0.6) → StochasticDepth(0.9)
输出维度：192
```

**分支B：风格统计特征分支（Stylometric Features）**
```
输入特征包括：
  - 基础统计：字符数、单词数、平均单词长度
  - 风格特征：大写字母比例、标点符号频率（12种标点）
  - 高级特征：字符n-gram熵（n=2,3,4）
  - 句子特征：长度分布统计（均值、标准差、偏度、峰度）
  - 段落特征：段落数、段落比例
  - 标点二元组：特定标点组合模式

网络结构：
  Stylo → Linear(192) → LayerNorm → GELU → Dropout(0.6)
        → StochasticDepth(0.9) → Linear(128) → LayerNorm
        → GELU → Dropout(0.6) → StochasticDepth(0.9)
输出维度：128
```

**分支C：字符级CNN分支（CharCNN）**
```
输入：字符序列（最大长度500）
字符嵌入维度：48
卷积核配置：4个不同大小的卷积核
每个卷积核：48个filter
输出维度：128（4 kernels × 48 filters → projection）
```

#### 2. 交叉注意力融合机制（CrossAttentionFusion）

```
融合维度：256
注意力头数：4
机制：多头注意力机制让三路特征相互交互
作用：捕捉不同类型特征之间的关联
```

#### 3. 分类器头部

```
融合特征(256) → Linear(128) → GELU → Dropout(0.6)
              → Linear(64) → GELU → Dropout(0.6)
              → Linear(3) → Softmax
```

### 关键技术亮点

#### 1. StochasticDepth（随机深度）
- **原理：** 训练时随机跳过某些层，测试时使用所有层
- **存活率：** 0.9（10%的概率跳过）
- **作用：** 提高泛化能力，防止过拟合
- **位置：** 在TF-IDF和风格特征分支中使用

#### 2. 混合精度训练（Mixed Precision）
- **使用：** torch.cuda.amp.autocast + GradScaler
- **优势：** 
  - 加速训练（使用FP16）
  - 节省显存
  - 保持数值稳定性

#### 3. OneCycleLR学习率调度
- **策略：** 学习率先从5e-4上升到1e-3，然后下降
- **优势：** 
  - 快速收敛
  - 避免局部最优
  - 提高最终性能

#### 4. 多模态特征融合
- **三种特征类型：**
  1. 文本语义（TF-IDF）
  2. 写作风格（统计特征）
  3. 字符模式（CNN）
- **融合方式：** 交叉注意力机制
- **优势：** 捕捉不同层次的作者风格

#### 5. 高Dropout率（0.6）
- **位置：** 所有全连接层
- **作用：** 强力正则化，防止过拟合
- **适用场景：** 小数据集（作者识别通常样本有限）

### 主要发现

1. **风格特征至关重要** - 第一次运行的成功很大程度上归功于详细的风格统计特征
